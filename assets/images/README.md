# Sky Beats reference images

## Files

- `sky-beats-brand-board.png` — consolidated visual direction covering the logo, palette, typography, illustration style, icons, UI examples, rewards, voice and graphic motifs.
- `jess-and-grace-reference.png` — primary character reference for Jess and Grace, including their clothing, headphones, aviation details, DJ equipment and overall illustration treatment.
- `jess-and-grace-white-background.png` — derived in-product version of the character artwork with a clean white backdrop; the supplied reference remains unchanged.

## Usage

- Keep these original files unchanged as source references.
- Use the character image for art direction and approved in-product placements where its crop remains readable.
- Use the brand board to guide new UI and assets; do not ship the entire board as an interface screen.
- Preserve the warm, expressive character treatment. Avoid tracing individual UI details from the board when a clearer accessible implementation is needed.
- Place derived exports in named subfolders such as `logos/`, `characters/`, `icons/` or `backgrounds/`.
