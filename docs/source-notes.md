# Source notes

## Original concept conversation

The initial Sky Beats concept and brand-guideline draft were developed in the ChatGPT quick chat titled [DJ Deck Recommendations](chatgpt-conversation://6a8820e3-f084-83ec-8953-f99259980ece).

The working application prototype was built and refined in the Codex task [Build a prototype based on the documents in this folder](codex://threads/01a0269d-adf8-7df0-b91a-e2d8f7503afd).

This project pack turns that temporary conversation into durable local documentation. If the chat and these files ever differ, treat the local project files as the current working specification unless the project owner says otherwise.

## Decisions carried into this pack

- Parent-and-child co-learning rather than teacher-and-student instruction
- Pioneer DJ DDJ-FLX4 as the reference controller
- Five-screen MVP: Home, Lesson, Challenge, Practice and Rewards
- Ten short missions, with the first five required for the initial usable build
- Manual controller confirmation in version 1 and optional Web MIDI later
- Local progress with no account or backend in the MVP
- Aviation-and-music visual language, including flight paths, patches and “Learn. Mix. Soar.”
- Cooperative play with no winners, individual scores or comparisons
- Shared crew rewards and a helper role for the player who is not touching the controller
- Both Jess and Grace treated as complete beginners
- DDJ-FLX4 connected to the Mac while Sky Beats operates as a manual companion guide
